使用说明

按顺序完成以下四步，即可维护并推送本周期的积分数据

建议每个考核周期开始时更新一次项目，周期内随时维护交付情况，最后同步并推送积分。
钉钉相关功能（表格导入、积分同步、消息推送）只能在本地版使用：先双击工作区里的「启动工作台」，再打开 http://localhost:3000 。公网版仅用于查看数据。
1
更新项目列表
项目列表 → 新增项目 → 从钉钉 AI 表格导入
  • 搜索并选择本周期的周报表（如「2026年Q4…」），确认导入当前周期的表，不要选上一季度。
  • 导入按「客户 + 负责人」去重：已存在的项目会更新阶段与来源字段，不会重复新增。
  • 负责人姓名需与「成员工作台」里的成员一致，否则会提示负责人不在系统成员中。
  • 待派单项目允许派单日期为空。
2
维护项目交付情况
项目列表 → 编辑项目
  • 核对每个项目的当前阶段（实施中 / 维护中 / 已移交 / 待派单）。
  • 设置本季度交付/移交：选「否」的项目不计入预计完成积分。
  • 确认模块实施积分与预计完成系数，它们决定预计完成积分。
3
同步当前积分
成员工作台 → 导入当前积分
  • 粘贴钉钉在线电子表格链接（含 /nodes/），点「读取预览」。
  • 预览核对「表格总积分 / 系统当前积分」与「表格目标 / 系统目标」，确认后点「确认同步」。
  • 同步会同时写入当前积分和季度目标；实施主管与表内为空的行自动跳过。
4
推送积分
负责人视图 → 推送积分 → 核对预览 → 确认推送
  • 预览会列出每位成员的当前积分、预计完成、季度目标、完成率与接收内容。
  • 成员收到「个人积分概览」；实施主管收到「团队汇总」，含各小组目标与预计完成率。
  • 没有匹配到钉钉账号的成员会标「无钉钉账号 · 跳过」，不会影响其他人发送。

常见问题

页面打不开 / 一直转圈？
双击「启动工作台」重新启动本地服务，然后访问 http://localhost:3000 。
点导入或推送提示「仅本地版可用」？
说明本机代理没启动：确认双击过「启动工作台」，并保持终端窗口运行。
导入后项目阶段没更新？
确认导入的是本周期（Q4）的周报表；导入是「按客户 + 负责人」更新，不会覆盖手工改过的其他字段。
推送时有人被跳过？
该成员在钉钉里匹配不到账号（如外部/引用用户），需在钉钉通讯录中确认后重新推送。
